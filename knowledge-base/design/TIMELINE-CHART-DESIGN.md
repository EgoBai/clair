# 分时图设计原则

## 核心要素
1. **价格曲线** - 蓝色实线 + 渐变填充，区分涨跌
2. **均价线** - 黄色虚线，实时反映当日均价
3. **基准线** - 昨收价灰色虚线，作为涨跌参考
4. **成交量柱** - 下方独立区域，红涨绿跌着色

## 交互设计
- 十字光标联动 Tooltip
- 时间轴仅显示整点/半点，避免拥挤
- 价格 Y 轴自动适配范围（含 padding）
- 成交量柱最大宽度 4px，保持紧凑

## 技术要点
- Canvas 渲染（大量数据点性能优先）
- smooth: true 平滑曲线
- areaStyle 线性渐变填充
- markLine 标注昨收价
- 双 grid 布局（价格区 + 成交量区）
