# 股东增减持设计文档

## 概述
股东增减持是反映机构和个人投资者对个股信心的重要指标。增持通常被视为看好信号，减持可能预示套现压力。

## 变动类型
| 类型 | 说明 | 信号 |
|------|------|------|
| increase | 增持 | 看好（红） |
| decrease | 减持 | 看空（绿） |
| new | 新进 | 关注（蓝） |
| exit | 退出 | 警惕（灰） |

## API 设计
| 端点 | 说明 |
|------|------|
| /api/shareholder-changes | 增减持列表（按类型筛选） |
| /api/shareholder-changes/overview | 概览（TOP增/减持排名） |
| /api/shareholder-changes/:symbol | 个股历史 |

## 可视化
- 增/减/新/退 四色统计卡片
- 表格按变动股数排序
- 机构/个人标签区分

## 限售股解禁

### 解禁类型
| 类型 | 说明 |
|------|------|
| 首发原股东限售 | IPO时原始股东 |
| 定向增发机构配售 | 定增机构配售 |
| 股权激励限售 | 员工激励计划 |
| 追加承诺限售 | 股东承诺锁定 |

### 关键指标
- **unlockRatio**: 解禁股数/流通股数 × 100%
  - >10%: 高风险（红色）
  - 5-10%: 中等（橙色）
  - <5%: 低风险（绿色）
- **marketValue**: 解禁市值 = 解禁股数 × 股价

### 可视化
- 日历组件标记解禁日期
- Badge 显示解禁事件数量
- 市值大标红 (>100亿)
- 排行表按市值降序
