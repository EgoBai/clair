# 股票对比分析设计

## 设计目标
- 支持 2-5 只股票横向对比
- 多维度雷达图可视化
- 柱状图直观对比
- 详细指标表格

## 对比维度（10个指标）

| 指标 | 方向 | 说明 |
|------|------|------|
| 市盈率(PE) | 越低越好 | 估值水平 |
| 市净率(PB) | 越低越好 | 资产估值 |
| ROE | 越高越好 | 盈利能力 |
| 毛利率 | 越高越好 | 产品竞争力 |
| 净利率 | 越高越好 | 综合盈利能力 |
| 营收增长率 | 越高越好 | 成长性 |
| 利润增长率 | 越高越好 | 盈利增长 |
| 资产负债率 | 越低越好 | 财务风险 |
| 流动比率 | 越高越好 | 偿债能力 |
| 股息率 | 越高越好 | 分红能力 |

## 雷达图（6维度）

| 维度 | 说明 |
|------|------|
| 盈利能力 | 综合ROE/毛利率/净利率 |
| 成长能力 | 营收/利润增长率 |
| 估值水平 | PE/PB综合评分 |
| 财务稳健 | 资产负债率/流动比率 |
| 现金流 | 经营现金流质量 |
| 分红能力 | 股息率/分红历史 |

## 可视化方案

### Tab 1: 雷达图对比
- Recharts RadarChart
- 每只股票一条线（颜色循环）
- 6个维度轴

### Tab 2: 柱状图对比
- 分组柱状图
- 8个核心指标
- X轴指标名，Y轴数值

### Tab 3: 详细对比表
- 行：10个指标
- 列：N只股票
- 涨跌着色
- 指标方向标注

## 交互设计
- 股票选择器（最多5只）
- Tag 展示已选股票
- 支持删除单只
- 一键刷新
