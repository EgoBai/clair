# 除权除息复权处理设计

## 概述

A股股票在分红、送股、转增时会产生除权除息，导致股价跳变。复权处理的目标是消除这些非交易因素对价格的影响，使历史价格具有可比性。

## 核心概念

### 除权除息类型

| 类型 | 说明 | 对股价的影响 |
|------|------|------------|
| 现金分红 | 每股派发现金 | 股价下调 = 派息金额 × (1 - 税率) |
| 送股 | 用未分配利润送红股 | 股价下调，股数增加 |
| 转增 | 用资本公积转增股本 | 股价下调，股数增加 |
| 配股 | 向现有股东配售新股 | 需要额外资金投入 |
| 拆股 | 拆分股份 | 等比例调整 |

### 复权方式

#### 前复权 (Forward Adjustment)
- 以**最新价格**为基准
- 历史价格向前调整
- 适合: 看当前价格走势，做技术分析
- 公式: `调整价 = (原价 - 累计派息) / 累计复权因子`

#### 后复权 (Backward Adjustment)
- 以**首日价格**为基准
- 后续价格向后调整
- 适合: 看长期收益，计算总回报
- 公式: `调整价 = 原价 × 累计复权因子 + 累计派息`

### 税率规则

| 持股期限 | 税率 |
|---------|------|
| < 1个月 | 20% |
| 1个月 ~ 1年 | 10% |
| > 1年 | 免税 |

## 实现要点

### 1. 复权因子计算

```
复权因子 = Π(1 + 送转比例[i])，从基准日累计
```

### 2. 除权参考价

```
除权参考价 = (股权登记日收盘价 - 每股派息(税后)) / (1 + 送股比例 + 转增比例)
```

### 3. 边界情况处理

- 同一天多次除权事件 (合并处理)
- 负价格防护 (Math.max(0, ...))
- 空数据 / 数据不足
- 零除数保护

## Wind 数据标准参考

- 价格精度: 2位小数
- 成交量: 整数 (手)
- 金额: 2位小数 (元)
- 涨跌幅: 2位小数 (%)
- 除权日: 股权登记日次一交易日

## 测试策略

- 纯现金分红场景
- 纯送股场景
- 混合方案场景
- 前复权收益率一致性验证
- 多次除权事件累积效应
- 边界条件 (空数据、零价格)
