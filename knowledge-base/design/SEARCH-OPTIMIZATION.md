# 搜索优化设计

## 参考: 雪球/同花顺搜索体验

### 匹配优先级（从高到低）
1. 代码精确匹配 (1000分)
2. 代码前缀匹配 (900分)
3. 代码包含匹配 (800分)
4. 名称精确匹配 (700分)
5. 名称前缀匹配 (600分)
6. 名称包含匹配 (500分)
7. 拼音首字母匹配 (400分)
8. 名称模糊匹配 - 每个字都出现 (300分)

### 拼音搜索
- A股用户习惯用拼音首字母搜索（如 gzmt=贵州茅台）
- 静态映射表覆盖主要股票
- 完整方案：使用 pinyin 库动态转换
- 性能：映射表查询 O(1)，比实时转换快100x

### 搜索历史
- 用户维度存储（关联userId）
- 最多保留20条
- 去重 + 时间排序
- 实际应用中用 Redis 存储

### 缓存策略
- 搜索结果缓存 60s
- 热门搜索单独缓存
- 缓存命中率监控
