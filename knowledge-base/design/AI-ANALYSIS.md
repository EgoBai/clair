# AI 智能分析设计

## 设计理念
参考同花顺 i问财功能，构建基于多维度评分的智能选股系统。

## 核心引擎

### 1. 综合评分体系 (0-100)
```
总评分 = 技术面 × 0.35 + 基本面 × 0.30 + 动量 × 0.20 + (100-风险) × 0.15
```

#### 技术面评分
- MA 多头/空头排列 (+/-15)
- RSI 超买超卖 (+/-10)
- MACD 金叉死叉 (+/-10)
- 布林带位置 (+/-8)

#### 基本面评分
- PE 估值水平 (+/-15)
- ROE 盈利能力 (+/-15)
- 营收增长 (+10)

#### 动量评分
- 5日动量
- 20日动量

#### 风险评分
- 波动率
- 高PE风险
- 涨停风险

### 2. 推荐等级
| 等级 | 评分 | 含义 |
|------|------|------|
| strong_buy | ≥80 | 强烈推荐 |
| buy | 65-79 | 建议买入 |
| hold | 45-64 | 持有观望 |
| sell | 30-44 | 建议卖出 |
| strong_sell | <30 | 强烈卖出 |

### 3. 智能预警类型
- **limit_up/down**: 涨跌停
- **breakout**: 放量突破
- **rsi_extreme**: RSI 极端值
- **abnormal_volume**: 成交量异常
- **macd_cross**: MACD 金叉/死叉

### 4. 行业轮动分析
- **leading**: 领涨板块
- **heating**: 升温板块
- **cooling**: 降温板块
- **lagging**: 落后板块

## 技术指标实现
- MA: 简单移动平均
- EMA: 指数移动平均
- RSI: 相对强弱指标 (14日)
- MACD: 指数平滑异同移动平均线
- BOLL: 布林带 (20日, 2倍标准差)

## API 设计
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | /api/ai/recommendations | AI选股推荐 |
| GET | /api/ai/analyze/:symbol | 单股分析 |

| GET | /api/ai/sector-rotation | 行业轮动 |
| GET | /api/ai/market-sentiment | 市场情绪 |
