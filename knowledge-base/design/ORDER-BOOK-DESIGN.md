# 盘口数据设计

## 功能概述
实时盘口数据展示，包含买一~买五、卖一~卖五档位信息，委比计算，以及分时数据曲线。

## 核心概念

### OrderBook 结构
- **bids**: 买盘5档，价格从高到低排列
- **asks**: 卖盘5档，价格从低到高排列
- **bidAskRatio**: 委比 = (总买量 - 总卖量) / (总买量 + 总卖量) × 100%
- **amplitude**: 当日振幅

### 分时数据
- 240个数据点（交易日9:30-15:00，排除午休）
- 每分钟一个数据点
- 包含：价格、成交量、均价、涨跌幅

## 设计原则

1. **数据密度** - 5档展示是A股标准，深市Level2有50档
2. **实时性** - 盘口数据变化快，需要WebSocket实时推送
3. **视觉层次** - 买盘红色在上，卖盘绿色在下（与行情软件一致）
4. **委比可视化** - 进度条直观展示买卖力量对比

## A股特性
- 最小交易单位：100股
- 价格涨跌幅限制：±10%（ST股±5%）
- 科创板/创业板：±20%
