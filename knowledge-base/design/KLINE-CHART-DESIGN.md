# K线图设计原则

## TradingView 参考

### 统一视图设计
- K线 + 成交量 + 技术指标三合一布局
- 主图(K线)占比 55-60%，副图(成交量/指标)占比 18-20%
- 十字光标联动主图和副图
- DataZoom 滑块控制时间范围

### 交互细节
- 缩放：鼠标滚轮控制时间轴缩放
- 十字光标：显示日期、OHLCV、MA值
- Tooltip格式化：涨跌颜色、单位转换(亿/万)
- 导出为图片功能

### 性能优化
- 大数据量使用 canvas 渲染
- 动画关闭(animation: false)避免重绘卡顿
- useMemo 缓存 option 计算
- symbol: 'none' 减少绘制点

## 技术指标叠加
- MA均线叠加在K线主图上
- EMA使用虚线区分
- 副图可切换：成交量 / MACD / KDJ / RSI
- 各指标独立阈值标记(如RSI 30/70)

## 中国股市特殊性
- 红涨绿跌（与国际市场相反）
- 涨跌停板制度
- T+1交易
