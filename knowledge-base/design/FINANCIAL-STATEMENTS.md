# 财务报表可视化设计

## 设计目标
- 三表联动展示（资产负债表、利润表、现金流量表）
- 多期对比（同比分析）
- 关键指标卡片化
- 参考 Wind / Bloomberg 数据展示风格

## 数据模型

### 资产负债表 (BalanceSheet)
- 资产：总资产、流动资产、货币资金、应收账款、存货、固定资产
- 负债：总负债、流动负债、短期借款、长期借款、应付账款
- 权益：股东权益、实收资本、资本公积、留存收益
- 衍生指标：流动比率、速动比率、资产负债率、权益乘数

### 利润表 (IncomeStatement)
- 收入：营业收入、其他收入
- 成本：营业成本、销售费用、管理费用、财务费用、研发费用
- 利润：毛利润、营业利润、净利润
- 每股指标：EPS
- 衍生指标：毛利率、净利率、ROE、ROA

### 现金流量表 (CashFlow)
- 经营活动现金流
- 投资活动现金流
- 筹资活动现金流
- 衍生指标：经营现金流/净利润、自由现金流

## 可视化方案

### 摘要页
- 8个核心指标卡片（ROE/毛利率/净利率/资产负债率/营收增长/利润增长/流动比率/ROA）
- 盈利能力雷达图（6维：ROE/毛利率/净利率/ROA/收入增长/利润增长）
- 资产构成饼图

### 资产负债表页
- 多期对比表格
- 资产/负债/权益柱状图

### 利润表页
- 多期对比表格
- 收入利润趋势折线图
- 利润率趋势折线图

### 现金流量表页
- 三项现金流卡片
- 现金流堆叠柱状图

## 设计原则
1. 金额格式化：万亿 → 亿 → 万，自动适配量级
2. 趋势着色：增长绿色，下降红色
3. 多期支持：最多10期数据
4. 响应式：移动端卡片单列，表格横向滚动
