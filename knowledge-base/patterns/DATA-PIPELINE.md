# 数据流水线设计模式

## 设计目标
构建高效、可靠的金融数据处理流水线，支持从数据采集到前端展示的全链路处理。

## 流水线架构

```
数据源 → 采集 → 清洗 → 验证 → 转换 → 存储 → 分发 → 展示
```

### 阶段说明

| 阶段 | 职责 | 关键技术 |
|------|------|---------|
| 采集 | 多数据源适配 | 适配器模式、速率限制 |
| 清洗 | 格式统一、去重 | 数据标准化管道 |
| 验证 | 完整性/准确性校验 | 阈值检测、交叉验证 |
| 转换 | 指标计算、复权 | 技术指标引擎 |
| 存储 | 持久化 | PostgreSQL + 索引优化 |
| 分发 | 实时推送 | WebSocket + 缓存 |
| 展示 | 可视化 | ECharts + 虚拟化 |

## 核心模式

### 1. Transform Pipeline
- 函数式数据变换链
- 支持同步/异步混合
- 每步可插拔

### 2. Validation Pipeline
- 多级校验（格式→范围→逻辑）
- 错误收集而非快速失败
- 质量评分机制

### 3. Batch Processing
- 分批处理避免阻塞
- 可配置批次大小
- 进度追踪

### 4. Deduplication
- 按业务键去重
- 保留最新/最高质量版本
- 时间窗口内去重

### 5. Data Aggregation
- VWAP (成交量加权均价)
- 按时间窗口聚合
- 多维分组汇总

## 性能优化
- 大批量数据分块处理，每块让出主线程
- 使用 Set/Map 加速去重和查找
- 预计算常用聚合指标
- 增量更新而非全量重算

## 数据质量保障
- 入库前10维度校验
- 交叉验证（三表联动）
- 异常数据隔离
- 质量评分低于阈值自动告警
