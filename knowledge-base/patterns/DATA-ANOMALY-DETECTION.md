# 数据异常检测模式

## 概述
金融行情数据的质量直接影响分析结果的可靠性。本文档总结了A股行情数据的异常检测方法论。

## 异常类型矩阵

| 异常类型 | 严重程度 | 检测方法 | 典型场景 |
|---------|---------|---------|---------|
| 价格跳变 | high/critical | 相邻K线收盘价变动超阈值 | 除权除息、数据错误 |
| 成交量异常 | medium/high | 滑动窗口标准差 (Z-score > 3) | 突发消息、停牌复牌 |
| 价格倒挂 | critical | high >= max(open,close), low <= min(open,close) | 数据写入错误 |
| 负价格 | critical | 价格 < 0 | 数据错误 |
| 零成交量 | high | volume=0 但 turnover≠0 | 数据不一致 |
| 涨跌幅超限 | high | 超过±20% (注册制) | 除权、数据错误 |
| 精度异常 | low | 小数位数超规范 | 数据源差异 |
| 缺失数据 | medium | 交易日间隔 > 5天 | 数据采集遗漏 |

## 质量评分算法

```
score = 100 - (totalPenalty / maxPenalty) * 100

severityWeights = {
  critical: 10,
  high: 5,
  medium: 2,
  low: 0.5
}

totalPenalty = Σ severityWeights[anomaly.severity]
maxPenalty = totalRecords * 2  // 每条记录最大扣2分
```

## 数据精度标准 (参考Wind)

| 指标 | 精度 | 有效范围 |
|------|------|---------|
| 价格 | 2位小数 | ≥ 0 |
| 成交量 | 整数 | ≥ 0 |
| 成交额 | 2位小数 | ≥ 0 |
| PE | 2位小数 | -500 ~ 500 |
| PB | 2位小数 | -50 ~ 100 |
| ROE | 2位小数 | -100% ~ 100% |
| 涨跌幅 | 2位小数 | -20% ~ 20% (常规) |

## 最佳实践

1. **批量检测**: 对历史数据一次性全量检测，生成质量报告
2. **实时监控**: 对新数据实时检测，异常时告警
3. **分级处理**: critical 级别自动隔离，medium 级别标记警告
4. **数据修复**: 对于可修复的异常 (如精度问题)，自动修正
5. **趋势跟踪**: 记录质量评分趋势，发现数据源质量变化
