# 中间件管道测试模式

## 设计原则

中间件管道是现代Web框架的核心架构模式。测试应覆盖：

1. **执行顺序** — 多中间件按注册顺序执行
2. **短路返回** — 不调用 `next()` 可中断链
3. **错误传播** — try/catch 包裹整个链
4. **上下文传递** — 中间件间共享数据
5. **组合测试** — 完整请求生命周期

## 测试策略

```
beforeEach → 创建独立中间件实例 → 执行管道 → 验证上下文状态
```

### 关键断言点

- 中间件执行次数（called数组追踪）
- 短路后后续中间件不执行
- 异常被错误处理中间件捕获
- metadata在中间件间正确传递
