# 数据源集成设计

## 架构

```
DataSourceManager
├── Tushare (优先级1, 200次/分)
├── AKShare (优先级2, 300次/分)
├── 东方财富 (优先级3, 500次/分)
└── 新浪财经 (优先级4, 600次/分)
```

## 核心组件

### 1. DataSourceManager
- 数据源注册与管理
- 容灾自动切换（主 → 备 → 应急）
- `fetchWithFallback()`: 尝试所有可用源
- `checkDataQuality()`: 数据质量检查
- `getSourceStatus()`: 数据源状态监控

### 2. RateLimiter
- 滑动窗口限流（60秒窗口）
- 自动等待配额恢复
- 配额使用追踪

### 3. DataUpdateScheduler
- 定时任务注册/取消
- 任务状态查询
- 优雅停止所有任务

## 数据质量检查

### 检查项
- 必填字段缺失
- 数值范围异常
- 数据类型不匹配

### 质量评分
```
score = (validRecords / totalRecords) * 100
```

## 容灾策略
1. 按优先级尝试数据源
2. 失败时自动降级到下一个源
3. 记录每个源的成功率和延迟
4. 最终所有源失败返回错误

## 设计原则
1. **统一接口**: 所有数据源实现相同接口
2. **渐进降级**: 优先使用高质量数据源
3. **速率控制**: 尊重每个源的 API 限制
4. **可观测性**: 全面的状态监控
