# Round 361-369 — 交易分析引擎扩展 2026-03-31

## 本次迭代总览

新增 9 个专业分析引擎，覆盖交易微观结构、衍生品、风险管理、组合分析等领域。

## 新增引擎

### 1. 做市商分析引擎 (15 tests)
- **报价质量分析**: 平均spread、标准差、报价量、成交率、价格改善率
- **库存状态分析**: 当前/最大库存、利用率、净流量、持有期、偏斜度
- **逆向选择分析**: VPIN(Volume-Synchronized PIN)、毒性流量比率、毒性等级
- **做市商绩效**: PnL估算、spread捕获、逆向选择成本、胜率
- **报价动态**: 时间序列趋势、报价频率、取消/修改计数

### 2. 多时间框架分析引擎 (10 tests)
- **单框架趋势**: MA20/50、RSI、ROC、成交量确认
- **多框架对齐**: 对齐分数、主导时间框架、共振信号检测
- **动量分析**: ROC、MACD、成交量动量、加速度
- **高框架环境**: 偏向判断、关键支撑阻力、回撤深度

### 3. 期权Greeks引擎 (14 tests)
- **Black-Scholes**: Delta、Gamma、Theta、Vega、Rho
- **Greeks曲面**: 多行权价×多到期日
- **组合风险**: 净Delta/Gamma/Vega/Theta、对冲比率、盈亏平衡
- **隐含波动率**: Newton-Raphson反算

### 4. 交易成本分析v3 (12 tests)
- **滑点分析**: 按方向/规模分类
- **市场冲击**: Almgren-Chriss简化模型
- **交易所分析**: 成交率、延迟、价格改善、毒性评分
- **执行质量评分**: 综合评分 + 改进建议
- **成本分解**: 显性(佣金/印花税) + 隐性(价差/冲击)

### 5. 相关性体制检测引擎 (12 tests)
- **体制检测**: 低/正常/高/危机 + Risk on/off
- **断点检测**: t检验 + 前后对比
- **动态相关性**: 滚动/EMA/DCC-GARCH简化
- **尾部依赖**: 上下尾依赖、不对称性、危机放大效应
- **稳定性分析**: 最稳定/最不稳定资产对

### 6. 异常检测引擎 (15 tests)
- **多方法**: Z-Score、IQR、移动平均、EWMA
- **综合检测**: 多方法投票共识
- **时间序列异常**: 点异常/上下文异常 + 严重程度
- **多维异常**: 每维度评分 + 综合评分
- **趋势分析**: 异常率趋势 + 风险等级 + 预测

### 7. 组合压力测试v2 (9 tests)
- **6种预定义场景**: 崩盘/利率飙升/流动性危机/地缘/通胀/温和调整
- **敏感性分析**: 1bp/100bp/500bp影响
- **反向压力测试**: 目标损失→所需冲击
- **组合Greeks**: Beta、集中度风险

### 8. 因子归因引擎v2 (7 tests)
- **Brinson归因**: 配置/选股/交互效应
- **因子暴露**: 线性回归 + t统计量 + 显著性
- **风险归因**: 系统性/非系统性/跟踪误差
- **风格分析**: 成长/价值/动量/质量/规模/低波

### 9. 波动率期限结构引擎 (10 tests)
- **期限结构分析**: 斜率/曲率/contango/backwardation/隐含-实现价差
- **波动率曲面**: 微笑/偏斜/到期日调整
- **波动率体制**: 低/正常/升高/高/极端 + 百分位/Z-Score/Vol-of-Vol
- **波动率交易信号**: 买入/卖出/中性 + 策略/止盈止损/风险收益比
- **波动率锥**: 最小/25%/中位/75%/最大 + 当前百分位

## 关键设计原则

1. **纯函数设计**: 所有引擎无副作用，便于测试和复用
2. **边界处理**: 空数据/不足数据返回合理默认值
3. **类型安全**: 完整TypeScript类型定义
4. **数学严谨**: 使用标准金融数学公式(BS、Almgren-Chriss、VPIN等)
5. **可配置性**: 阈值/窗口大小等参数可调整
