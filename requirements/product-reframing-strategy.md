## 1. 产品哲学重构：信息工具 → AI-native 游戏化体验循环

- **旧范式**：用户主动"查数据 / 看整合 / 做分发"（被动消费信息）。
- **新范式**：AI 主动伴生、引导、反馈、陪练，用户在 **探索→求证→决策→复盘→成长** 闭环中持续获得进步感（主动建构投研能力）。
- **一句话定调**：把澄观从"投研信息工具"重构为"**AI-native 的投研成长伙伴**"——用真实大模型重做每一处体验，用游戏化循环把枯燥投研变成可坚持、可成长的旅程。
- **差异化底线**：拒绝"信息聚合 / 展示 / 分发"类工具复制品；价值在于**体验层（伴生 + 成长 + 叙事）**，而非堆功能。深层 AI 能力是主战场，不是模型接入本身（模型通道 `aiService` 已具备）。

> **D11 核心循环深度（已决）**：游戏化不止于表象系统，须从用户**首次进入**起铺设完整**核心循环**——监控 / 监测 → 筛选 → 追踪 → 回测 / 复盘 → 策略搭建 → 指标 / 特征 / 方法沉淀；按多行业交叉专家视角做最专业设计，使成长体系服务于核心能力建设，而非用游戏化掩盖投机。
- **已决（LLM 供应商）**：默认 provider = **DeepSeek（预算内）**，并保留多模型适配注册表以便切换；不锁定单一厂商，成本可控。

## 2. 体验循环与每阶段 AI 角色

> 阶段键（canonical key）与 `gamification-framework-schema.md` 对齐：`discover / research / decide / review / levelup`。注：`frontend-experience-design-language.md §1.4` 将首阶段显示为 "Explore（探索）"，实即 `discover`——二者为同一概念的不同展示名（见文末冲突说明）。

| 阶段 | key | 界面意图 | AI 角色（CompanionState.loopPhase） | 反馈 / 成长 |
|---|---|---|---|---|
| 探索 | discover | 市场全景、潜力雷达、行业地图 | 抛出观察、"今日值得看"引导 | 发现新标的得探索点 |
| 求证 | research | 个股诊断、多信号、回测、因子 | 调取证据、多视角挑战假设 | 分析被验证→能力分+ |
| 决策 | decide | 策略模板、自选信号、组合 | 可解释的风险 / 机会摘要 | 决策日记待复盘验证 |
| 复盘 | review | 复盘页、笔记、投资日志 | 对照当初判断、标记偏差 | 周度成长报告 |
| 成长 | levelup | 成就、旅程进度、伙伴升级 | 解锁新阶段、庆祝动效 | 里程碑惊喜 |

## 3. 现有功能 AI-native 三档分级（A / B / C）

- **A 已真 LLM**：模型通道已接通、上下文已注入，缺的是数据真实性与基建健壮性（超时 / 重试 / 熔断 / 降级）。
- **B 真 LLM + 假/演示数据**：模型接通，但喂硬编码 mock（含 TODO），补真实数据即成正样。
- **C 规则引擎**：无 LLM，纯规则 / 模板 / 抽取式，需整体升级为 AI-native。

| 功能（产品 7 模块） | 档位 | 现状证据 |
|---|---|---|
| 个股对话（Individual-Stock Chat） | **A** | `/ai/chat` 已注入板块 / 个股 / 自选行情并真实调用 LLM |
| 复盘提醒（Review Reminders） | **A** | 基于 `/ai/daily-briefing`、复盘 / 诊断端点（已通 LLM），需补真实数据 + 调度 |
| AI 业绩解读（AI Earnings Interpretation） | **B** | LLM 接通但财务数据多为硬编码 mock（如 `/ai/diagnose` 类），需 grounding |
| 知识库（Knowledge Base） | **C** | demo / 模板润色，无真实结构化与跨笔记关联 |
| 智能选股（Smart Stock-Pick） | **C** | `smartScreeningEngine` 因子规则引擎，无 LLM 推理 |
| 研报摘要（Research Summary） | **C** | `researchReportAnalysisEngine` 抽取式，非生成式 |
| 社区 / 笔记（Community / Notes） | **C** | 静态内容，缺 AI 辅助创作与自动关联 |

## 4. 七模块 AI-native 升级地图（方向 + 价值）

| 模块 | 当前档 | 升级方向（无代码） | 用户价值 |
|---|---|---|---|
| 知识库 | C | 真实 LLM 润色 + 结构化（标签 / 策略 / 教训）+ 跨笔记语义关联（RAG）（**已决 D13：RAG 纳入 P1**） | 沉淀可被检索复用的投研记忆 |
| 智能选股 | C | LLM + 因子混合推理：自然语言意图 → 因子组合 + 逻辑解释（因子保留为 AI 信号源） | 用"说人话"的方式找到目标股 |
| AI 业绩解读 | B→A | 接入真实财务 / 财报数据，跨期对比 + 风险点提取（长文本 / 多模态） | 读懂一份财报背后的机会与雷 |
| 研报摘要 | C | 抽取式 → 生成式 + 观点追问 + 多研报交叉验证 | 一篇研报 30 秒抓住核心观点 |
| 复盘提醒 | A | 强化真实数据 grounding + 定时触达 + 预期 vs 现实归因 | 坚持复盘，形成纪律 |
| 社区 / 笔记 | C | AI 辅助创作 + 自动关联相似标的 / 笔记 | 让记录变轻、变有用 |
| 个股对话 | A | 强化 RAG（财报 / 研报 / 资金流检索增强）+ 承载伴生关系语气 | "越聊越懂你"的专属投研伙伴 |

## 5. D4 数据源评估与推荐

评估维度：可靠性 / 稳定性 / 成本 / 覆盖度。

| 数据源 | 覆盖（A股 / 资金流） | 国际 / 外资 | 成本 | 可靠性 | 结论 |
|---|---|---|---|---|---|
| **Tushare Pro** | 个股资金流 / 北向 / 南向 / 龙虎榜 / 融资融券 / 财务全 | 弱（港美股另申） | 积分≥5000≈充值 500 元 | 高（标准化落库） | **A 股主源** |
| **AkShare** | 全覆盖（东财 / 新浪爬虫） | 部分 | 免费无 token | 中（无 SLA，易失效） | **A 股兜底** |
| **Alpha Vantage** | 美股 / ETF / 外汇 | 强（NASDAQ 授权合规） | 免费 25 次/天，付费 $49.99/月起 | 高（99.5% SLA） | **国际资金主源** |
| 东方财富 / 腾讯 / 新浪 公开 API | 资金流 / 北向 / 龙虎榜 | 无 | 免费 | 低（反爬 / 风控） | 后端代理取实时 |

**明确推荐（对齐已确认决策 D4）**

- A 股主源：**Tushare Pro**（积分≥5000），稳定标准化，覆盖个股大单 / 主力净流入 / 北向 / 南向 / 龙虎榜 / 融资融券。
- A 股兜底：**AkShare**（免费、覆盖全），主源异常时降级（已有 `DataSourceManager` 容灾链 + `fetchWithFallback()`）。
- 国际资金（外资流向 / 全球配置）：**Alpha Vantage**（合规授权、SLA 保障），必要时叠加 FMP。**（已决 D10：国际资金本期纳入开发）**
- **代理原则**：Tushare / AkShare 为 Python 服务端库，**必须后端**；东财 / 腾讯 / 新浪 / Alpha Vantage 即使可直连也**须后端代理**（CORS、反爬风控、密钥保护）。**前端不直连任何外部源**，统一经后端 `/api/*`，并保留 `demoData` 兜底（沿用现有策略）。
