# 下一阶段功能增强 · 方向框架

> Hermes 宏观思考 + 竞品调研 + 可行性评估 | 2026-06-25  
> 目标：识别投资者最关心的关键信息维度，做前期框架设计，逐步融入现有产品

## 一、用户视角：投资者最关心什么（核心痛点排序）

按市场常见投资者决策权重排序：

1. **资金流向** — "钱去哪了" 是第一决策因素。主力/北向/大单资金动向。
2. **交易拥挤度** — "别人都在哪" 是风险/机会的双面信号。机构通过拥挤度判断赛道泡沫或冷门反转。
3. **机构研报** — "专业人士怎么看" 是信息差消弭的捷径。原始链接 + AI 提炼 > 看二手解读。
4. 行业景气度（已有基础，持续优化）
5. 政策/资讯催化（已有 AI 市场解读覆盖一定层面）

## 二、各功能竞品对标

### 2.1 资金流向

| 竞品 | 功能名 | 做法 |
|------|--------|------|
| 同花顺 | 资金雷达 | 实时主力/散户资金流向，大单/中单/小单拆解，板块资金热力图 |
| 东方财富 | 资金流向 | 个股资金流日/周/月，北向资金，龙虎榜机构席位 |
| 富途牛牛 | 资金面 | 港股通/沪深港通，板块资金净流入排名，大额异动提醒 |
| 芝士财富 | 资金面 | 北向持仓变化、融资融券余额走势 |

**数据源可行性**：
- ✅ 北向资金：沪深港通每日额度（港交所公开），东方财富有汇总
- ⚠️ 主力/散户资金：需要成交单拆解（L2 行情），腾讯免费行情无此粒度
- ✅ 板块资金：可用 daily_quotes 的成交额按板块汇总算"板块资金热度"
- ✅ 自研替代：`板块成交额 / 全市场成交额 = 板块资金占比`，已有数据可算

### 2.2 交易拥挤度

这是一个**机构研报高频概念**（2024-2025 年大量出现），竞品尚未充分产品化——**可做差异化功能**。

**定义**：某板块/个股的资金和关注度集中程度。高拥挤 = 赛道过度拥挤可能反转；低拥挤 = 关注不足可能有冷门机会。

**可自研的定量指标**（已有数据可算）：
| 指标 | 算法 | 数据源 |
|------|------|--------|
| 成交额占比 | 板块成交额 / 全市场成交额 | daily_quotes（已有） |
| 换手率排名 | 板块平均换手率 / 全市场平均换手率 | daily_quotes（已有） |
| 涨跌比集中度 | 板块内上涨家数占比 vs 全市场 | daily_quotes（已有） |
| 连板股密度 | 板块内涨停/连板股数量 | 可通过 change_percent > 9.5% 统计 |
| 融资余额/流通市值比 | 两融数据（需额外数据源） | ⚠️ 当前不覆盖 |

**竞品现状**：同花顺/东方财富无标准"拥挤度"产品化模块。部分券商 App（华泰涨乐财富通、中信证券）开始有"热度值"。**此功能可成为澄观差异化亮点**——机构视角 + 自研指标。

### 2.3 机构研报 · 原始链接 + AI 提炼

| 竞品 | 做法 |
|------|------|
| 东方财富 | 研报中心：按行业/机构分类，免费看标题+摘要，原始链接可跳 |
| 同花顺 iFinD | 付费终端，数千份研报，AI 摘要功能 |
| 慧博资讯 | 专业研报平台，覆盖主流券商 |
| 芝士财富 | 整合研报评级变动 + AI 总结 |

**实现路径（分步，逐步加深）**：

**Level 1: 研报摘要聚合（可行性高，风险低）**
- 数据源：东方财富研报中心公开 RSS/列表页（data.eastmoney.com/report）
- 提取：标题 + 机构名 + 评级 + 目标价 + 原始链接
- AI 提炼：LLM 摘要每日热点研报的核心观点（3-5 句）
- 输出：一个轻量列表，"今日机构都在看什么"

**Level 2: 个股研报关联**
- 在 StockDetailPage 展示该股的历史研报列表+AI提炼
- 关联维度：symbol → 最近30天研报

**Level 3: 研报搜索引擎（远期）**
- 全文搜索 + AI Q&A（"找出所有看多 AI 算力的研报"）

⚠️ **法律/合规风险**：
- 爬取研报全文 = 侵权（券商研报有版权）。**只提取标题+评级+原始链接是安全的（属于信息聚合，类似搜索引擎做法）**。
- AI 摘要应基于标题+公开摘要，不对原文做复制/分发。
- 东方财富研报列表页是公开数据（不需登录），定期量访问风险低。

## 三、与现有页面的融合方案

| 功能 | 现有融入点 | 新模块（必要时） |
|------|-----------|----------------|
| 资金流向 | DiscoverPage 板块景气度旁加"资金热度"列；StockDetailPage 加资金流图表 | 如数据维度多，可新建 FundFlowPanel |
| 交易拥挤度 | DiscoverPage 板块分析加"拥挤度"信号灯（🟢正常/🟡偏高/🔴拥挤） | 不独立建页——嵌入 DiscoverPage 作为信号指示器 |
| 机构研报 | StockDetailPage 加"机构观点"卡片（研报摘要+原文链接） | 如研报量大，可建"研报雷达"轻量页（Level 2+） |

**融合原则**：优先融入现有页面（做减法、不增加页面复杂度），只在功能体量够大时开新模块。

## 四、与 AI 知识库的联动

- 行业分类体系（申万二级 138 类）→ 支撑资金流向/拥挤度的**板块粒度**更精准
- 策略参数库 → 资金面维度可融入策略筛选（"主力资金净流入>5000万"作为筛选条件）
- 投资话术库 → AI 解读时可引用研报观点（"XX 券商给予买入评级，目标价 XX"）

→ 这三个新功能不是孤立的，是和 AI 知识库建设**协同推进的一个整体**。

## 五、优先级与启动顺序

```
P0: AI 知识库 · 行业分类重制 ← 当前启动（见 AI-KNOWLEDGE-BASE-PRD.md）
     ↓ 支撑
P1: 交易拥挤度（差异化功能，自研指标，数据已有）← 行业分类就绪后启动

     ↓

```

## 六、下一步（调研→设计→PRD→开发）

按用户要求，每项都不能先做，要遵循流程：

1. **宏观思考** ✅ 本文档（完成）
2. **客观市场调研** → 交易拥挤度需 A 股历史数据验证指标有效性（回测？历史样本？）；机构研报需东方财富研报列表 API 可达性验证

4. **开发计划** → 分 Phase 实现
5. **实现 & 验收** → 按计划执行
6. **阶段性复盘** → 每个 Phase 完成后检查是否在正确方向
