## 一、功能定位

### 1.1 核心价值

**帮助用户快速理解一个全新行业/产业/概念的全貌**

| 维度 | 传统方式 | AI 产业地图 |
|------|----------|-------------|
| 学习成本 | 阅读多篇研报（2-4小时） | 5分钟看懂产业链 |
| 信息获取 | 分散在各处 | 一站式可视化 |
| 投资逻辑 | 需要经验总结 | AI 自动梳理 |
| 标的发现 | 手动搜索 | 智能推荐 |

### 1.2 使用场景

1. **新手入门**：第一次接触"光模块"概念，想快速了解是什么、上下游是谁
2. **热点跟踪**：某概念突然爆发（如CPO），想快速了解产业链和受益标的
3. **深度研究**：想系统了解一个行业的投资逻辑和关键节点
4. **比较分析**：对比多个产业链的相似性和差异

## 二、数据模型

### 2.1 产业链数据结构

```typescript
// 产业链定义
interface IndustryChain {
  id: string;
  name: string;                    // 如 "AI算力产业链"
  description: string;             // 产业链概述
  theme: string;                   // 主题标签
  createdAt: string;
  updatedAt: string;
  
  // 产业链层级
  layers: ChainLayer[];
  
  // 关联数据
  relatedConcepts: string[];       // 关联概念
  relatedPolicies: string[];       // 关联政策
  marketDrivers: string[];         // 市场驱动因素
}

// 产业链层级
interface ChainLayer {
  id: string;
  name: string;                    // "上游" / "中游" / "下游"
  type: 'upstream' | 'midstream' | 'downstream' | 'support';
  description: string;
  
  // 该层级的细分环节
  segments: ChainSegment[];
}

// 产业链环节
interface ChainSegment {
  id: string;
  name: string;                    // 如 "光芯片"、"光模块"、"数据中心"
  description: string;
  
  // 核心公司
  companies: ChainCompany[];
  
  // 环节特征
  characteristics: {
    marketSize: string;            // 市场规模
    growthRate: string;            // 增速
    competitiveLandscape: string;  // 竞争格局
    barriers: string[];            // 进入壁垒
    keyDrivers: string[];          // 核心驱动因素
  };
  
  // 关联关系
  upstreamTo: string[];            // 上游环节ID
  downstreamTo: string[];          // 下游环节ID
}

// 产业链公司
interface ChainCompany {
  symbol: string;
  name: string;
  marketCap: number;               // 市值
  changePercent: number;           // 涨跌幅
  position: 'leader' | 'challenger' | 'follower';  // 市场地位
  competitiveAdvantage: string;    // 竞争优势
  revenueBreakdown: string;        // 收入结构
}
```

### 2.2 数据来源

| 数据类型 | 来源 | 更新频率 |

### 3.2 交互设计

#### 产业链图谱交互

1. **节点点击**
   - 点击环节节点 → 展开详情面板（公司列表、特征描述）
   - 点击公司 → 跳转股票详情页

2. **关系线交互**
   - hover 关系线 → 高亮上下游关系
   - 点击关系线 → 显示供应关系说明

3. **缩放平移**
   - 鼠标滚轮缩放
   - 拖拽平移
   - 双击节点居中

4. **筛选过滤**
   - 按市值筛选公司
   - 按涨跌幅排序
   - 按市场地位筛选（龙头/挑战者/跟随者）

#### 布局算法

```typescript
// 使用 Dagre 布局算法（有向图自动布局）
import dagre from 'dagre';

const layoutChainGraph = (chain: IndustryChain) => {
  const g = new dagre.graphlib.Graph();
  g.setGraph({ rankdir: 'LR', ranksep: 100, nodesep: 50 });
  
  // 添加节点
  chain.layers.forEach(layer => {
    layer.segments.forEach(segment => {
      g.setNode(segment.id, { width: 150, height: 80 });
    });
  });
  
  // 添加边
  chain.layers.forEach(layer => {
    layer.segments.forEach(segment => {
      segment.downstreamTo.forEach(targetId => {
        g.setEdge(segment.id, targetId);
      });
    });
  });
  
  dagre.layout(g);
  return g;
};
```

## 六、技术选型

| 组件 | 技术方案 | 理由 |
|------|----------|------|
| 图谱可视化 | React Flow | 成熟的节点图库，支持自定义节点和边 |
| 布局算法 | Dagre | 有向图自动布局，适合产业链层级关系 |

| AI 生成 | DeepSeek v4-pro | 与现有系统一致 |
| 流式响应 | SSE | 与现有AI对话一致 |
