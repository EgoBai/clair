# AI 知识库建设 · 设计方案 PRD

> Hermes 后端领域 | 2026-06-25 | 宏观思考 → 市场调研 → 设计 → 计划 → 实现 → 复盘

## 一、目标与价值

**为什么做**：当前 Clair 的 AI 解读（market-insight/watchlist-summary/trade-analysis）已用 LLM，但**缺少结构化专业知识库支撑**。LLM 的精准度取决于两点：①prompt 里塞了多少专业约束 ②是否有细粒度数据。知识库解决两者。

**三子模块**：
1. **行业分类体系**（核心痛点：607 只分在一个"综合"里，用户已批评）
2. **策略参数库**（支撑 ScreenerPage 和未来策略推荐）
3. **投资话术库**（让 AI 输出更专业，不做独立 DB，嵌入 prompt 结构）

## 二、行业分类体系 · 选型

### 主流分类标准对比

| 标准 | 一级 | 二级 | 三级 | 特点 | 市场认同度 |
|------|------|------|------|------|------------|
| 申万 2021 | 31 | 138 | ~300 | 投资导向，更新勤，A股最主流 | ⭐⭐⭐⭐⭐ |
| 中信 | 30 | ~100 | - | 产业链视角，侧重上下游关系 | ⭐⭐⭐⭐ |
| 证监会 2012 | 19 | 90 | ~300 | 监管导向，法定的主营收入占比规则 | ⭐⭐⭐ |
| 中证 | 11 | 35 | ~200 | 简化版，强调投资属性 | ⭐⭐⭐ |
| GICS | 11 | 24/68/154 | - | 全球通用，MSCI/S&P标准 | ⭐⭐⭐ 外资用 |

### 竞品使用情况
- **同花顺/东方财富**：主用申万，同时提供中信、GICS 切换
- **富途牛牛**：主用申万，叠加自研概念/产业链标签
- **芝士财富**：自研"板块"概念，混合申万+热点主题

### 推荐方案：**申万 2021 二级 138 类 + 中信产业链标签**

**为什么申万而非自研或融合**：
- A 股市场事实标准（94% 机构研报用申万）
- 数据源可获得（腾讯/东方财富 API 返回申万分类）
- 用户最熟悉，无学习成本
- 138 个二级 → 从 31 个一桶浆糊变成每类约 40 只，粒度科学

**为什么叠加中信标签**：
- 中信的产业链视角（上游/中游/下游）对**产业地图**功能是天然增强
- 不改主分类，只是给股票多一条 `chain_tag` 可选项，不破坏现有系统
- 实现成本低（标签字段追加，不重构分类表）

**为什么不是三级 300 类**：三级虽更细但数据源不稳定（腾讯/东方财富不保证三级全覆盖），且每类 15-20 只过细 → 板块分析时样本不足、统计偏差大。二级 138 类 / 每类 ~40 只是最优粒度。

### 当前数据缺口

现状：`stocks.industry` 字段是旧数据（约 31 个一级分类，其中"综合"占了 2151→1823 只未分类股票），来源为关键词模糊匹配。精度不满足产品要求。

**目标**：每只股票分配到准确的申万 2021 二级行业（138 类），以及可选的申万一级 + 中信产业链标签。

## 三、策略参数库

### 目标
把 ScreenerPage 里硬编码的 8 个策略模板参数（价值/成长/动量/质量/红利/困境反转/AI 潜力/低估值修复）**结构化为配置式参数库**，支持：
- 前端展示"策略逻辑+核心指标+参数"（解决之前用户反馈的"没有筛选说明"）
- 未来新增策略只需加配置项，不改代码
- 后端 AI 策略推荐可引用参数库做约束

### 参数模板结构
```json
{
  "id": "value_investing",
  "name": "价值投资",
  "nameCn": "价值投资",
  "description": "低估值蓝筹，PE<15, PB<2, ROE>10%, 股息率>2%, 市值>200亿",
  "filters": {
    "peRange": [0, 15],
    "pbRange": [0, 2],
    "minRoe": 10,
    "minDividend": 2,
    "minMarketCap": 200e8,
    "industry": { "exclude": ["综合", "*ST"] }
  },
  "ranking": "pe_asc",
  "educationalNotes": {
    "whyPE": "市盈率=股价/每股收益，低PE代表市场对其估值定价保守——用7年利润就能收回投资成本",
    "whyROE": "ROE=净利润/净资产，反映企业用股东钱赚钱的能力，>10%是巴菲特选股门槛"
  }
}
```

- 富途牛牛 "选股器" 7 大策略
- 经典投资书籍参数（格雷厄姆、彼得·林奇）

## 四、投资话术库（轻量，嵌入 AI prompt 结构）

不建独立数据库。在 AI 解读 prompt 中嵌入结构化专业知识片段：

```
## 行业解读框架（申万二级 138 类）
- 银行: 关注净息差↓、不良率、拨备覆盖率、LPR走势
- 半导体: 关注国产替代率、晶圆厂稼动率、设备进口替代、AI算力需求
- 白酒: 关注批价、库存周期、消费升级/降级趋势、节前备货节奏
- 新能源: 关注补贴退坡影响、产能过剩风险、技术路线(磷酸铁锂vs三元)、海外关税

## 常用分析视角
- 量价关系: 放量上涨=进攻, 缩量下跌=蓄力, 天量天价=顶部信号
- 市场情绪: 涨停家数>150=亢奋, <30=冰点; 涨跌比>3=全面进攻, <0.5=防守
- 估值水位: 当前PE处于历史XX百分位, 低于30=低估区间, 高于70=高估区间
```

这部分直接嵌入 `/ai/market-insight-llm` 等的 system prompt 中，不增加 API/DB 结构。**零工程成本、即时生效**。
