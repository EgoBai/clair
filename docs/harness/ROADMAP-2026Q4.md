## 五、执行纪律（全 Sprint 生效）

1. 单通道: 生产源码在途即停并行；自动化启用前 push+干净树
2. 四证验收: grep/读文件/curl 或测试/e2e，子 Agent 自报一律复验
3. 诚实红线: 无真实数据→unavailable；禁 Math.random/零值顶替/硬编码
4. 假失败纪律: 判失败前空载复跑；rg 替代 grep；tsc 全量 OOM 用 esbuild
5. 每批收口: lead 逐文件 add+commit，严禁脏树与 git add -A
6. 阶段汇报: 每批验收结果按「交付/验证/残留/下一步」结构报用户
