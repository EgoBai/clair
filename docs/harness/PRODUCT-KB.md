# 产品知识库 — Clair (澄观)

> 持续更新。每次 CAPTURE 阶段追加条目。

## 产品愿景

**一句话**：帮助个人投资者每天花15分钟就能了解市场、找到标的、管理自选。

**不是什么**：
- 不是同花顺/东方财富的复制品
- 不是专业量化工具
- 不是社交交易平台

**是什么**：
- AI陪伴式投资研究助手
- 有温度的投资伙伴
- "AI帮你读懂A股"

| 功能 | 状态 | 用户价值 | 技术复杂度 |

## 用户旅程

```
每日旅程（15-30分钟）：
1. 打开澄观 → 发掘页看今日市场（3分钟）
2. 浏览AI解读 → 了解板块轮动（2分钟）
3. 筛选页找感兴趣的股票（5分钟）
4. 详情页看K线+AI诊断（5分钟）
5. 加入自选 → 管理组合（3分钟）
6. 复盘页回顾策略（5分钟）
```

## 设计原则

1. **AI是核心差异化** — 不是装饰，是真正的大模型驱动
2. **温暖不是冰冷** — 拟人化AI，不是数据终端
3. **一次做完** — 一个功能一次提交，端到端可用
4. **用户优先** — 只做用户能感知的改进
5. **红涨绿跌** — 中国A股惯例，绝不动摇
