# T-2611-01 解禁日历股票列裸 <a href> 丢失 /clair/ 前缀

> 状态：已收口（2026-11-03 修复，2026-11-04 补 E2/E3 门禁证据）
> 来源：docs/rsi/dev-loop-v1.md §7 真实样例；WorkBuddy 会话 2026-11-03 实测 154 条当月解禁记录

## 1. 目标（含来源依据）

- 现象：线上「解禁日历」点股票名跳出站点，落 GitHub 通用 404「There isn't a GitHub Pages site here.」
- 依据：frontend/src/pages/LockupCalendarPage.tsx:383 修复前为
  <a href={\`/stocks/\${record.symbol}\`} style={{ fontWeight: 600 }}>{record.name}</a>。
  裸 <a> 是整页导航，绕过 React Router basename（生产 base 为 '/clair/'），浏览器把
  /stocks/600519 解析为 https://egobai.github.io/stocks/600519，该路径无 Pages 站点。
  该页当月有 154 条真实解禁记录，点股票名即触发，属"正在发生"的用户可见缺陷，P0。
- 修复：改为 <Link to={\`/stocks/\${record.symbol}\`}>（LockupCalendarPage.tsx:383），
  并新增 frontend/src/__tests__/noRootAbsoluteAnchor.test.ts，把静态串/模板字面量等 6 种写法建模为自测用例。
