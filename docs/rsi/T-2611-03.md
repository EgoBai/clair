# T-2611-03 市场解读成交额与涨跌停改用市场宽度同源（剔除指数重复计入）

> 状态：已收口（2026-11-17 修复；契约断言手跑红→绿；线上 curl 两接口同值）
> 来源：handover/09 已知生产缺陷清单 / 线上首页实测取证（2026-11-17 01:56）

## 1. 目标（含来源依据）

- 现象：线上首页同屏「AI 市场解读」总成交 4.5 万亿，「市场宽度」1.46 万亿，差 3.08 倍；
  AI 卡 36 只涨停 / 168 只跌停，市场宽度 33 / 67，跌停虚高 2.5 倍。
- 依据：clair-worker/worker.js 修复前 handleMarketInsight 把原始 quotes 交给
  generateMarketInsight() 自行聚合：allQuotes 未剔除 9 条指数快照行（指数成交额=成份股合计，
  重复计入），涨跌停用扁平 >=9.9 / <=-9.9 判定，ST ±5%、创业板/科创板 ±20%、北交所 ±30%
  全部误判。同文件 /api/market/summary 已改用 loadBreadthSnapshot()，本端点漏修。
- 修复：handleMarketInsight 与 handleMarketSummary 同源，取 loadBreadthSnapshot()；
  涨跌家数/涨跌停/成交额全部取 breadth（涨跌停复用 computeBreadthSnapshot 的交易所涨跌停价
  判定，未新造第二套口径）；PE 分析仍用 quotes 但剔除指数行；快照不可用时整卡降级为
  unavailable（metrics 为空对象），不以 0 或旧口径顶替。
