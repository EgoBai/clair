# T-2611-02 指数详情开高低/成交额全空、裸代码匹配失败

> 状态：已收口（2026-11-04 17:20 修复并上线）
> 来源：本轮 Playwright 逐页巡检 13 个线上页面的唯一真缺口（handover/19 工具化后的首件产出）

## 1. 目标（含来源依据）

- 现象：线上「指数详情」页（/clair/index/sh000001）只显示收盘、涨跌幅与均线/RSI/评分，而「开盘 —、最高 —、最低 —、成交额 —」整排为空；顶部红条「未挂载端点：/api/market/index-top-movers/sh000001」；把地址换成裸代码 /clair/index/000001 时进一步退化为「指数数据不可用」。
- 依据：Worker `handleMarketIndices` 只映射 `symbol/name/closePrice/changePercent/volume/category` 六个字段，上游腾讯行情 `parts[5]（开盘）/[33]（最高）/[34]（最低）/[37]（成交额，万元）/[30]（时间戳）` 全部被丢弃；`/api/market/index-top-movers/:symbol` 在 worker.js 内无任何注册；前端 `IndexDetailPage` 用 `i.symbol === symbol` 精确比较，裸代码与 `sh000001` 不等。
- 修复范围：`clair-worker/worker.js`（字段映射 + dataSource 三态 + 新增 unavailable 端点）、`frontend/src/pages/IndexDetailPage.tsx`（null 安全 + 裸码归一）。
