# A股行情分析网站

一个专门反映A股行情的专业网站，提供实时行情、技术分析、选股策略和投资建议。

## 🎯 项目目标

1. **数据准确无误差**：多数据源交叉验证，确保数据可靠性
2. **更新及时**：实时行情、快速数据更新
3. **网站性能好**：快速响应，流畅体验
4. **多端适配**：PC、平板、手机全适配
5. **持续迭代**：每日检查，每周优化

## 📊 核心功能

### 数据展示
- 实时A股行情（沪深主板、创业板、科创板）
- 技术指标分析（MACD、KDJ、RSI、布林带等）
- 基本面数据（PE、PB、ROE、营收增长）
- 资金流向监控
- 板块轮动分析

### 选股工具
- 多因子选股模型
- 技术面选股
- 基本面选股
- 量化策略回测
- 自定义筛选

### 投资策略
- 每日投资建议
- 风险等级评估
- 仓位管理
- 止损止盈策略
- 市场情绪分析

## 🏗️ 技术架构

### 前端
- React 18 + TypeScript
- Ant Design / Material-UI
- ECharts / Recharts
- Tailwind CSS
- PWA支持

### 后端
- Node.js + Express
- Python（数据分析）
- PostgreSQL
- Redis
- RabbitMQ/Kafka

### 数据源
- 腾讯财经API
- 新浪财经API
- 东方财富API
- 聚宽/JQData
- 自建爬虫
